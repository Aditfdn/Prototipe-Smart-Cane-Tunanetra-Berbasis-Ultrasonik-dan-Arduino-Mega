# Design System Documentation

## Warna

### Biru

Digunakan pada:

* Tombol utama
* Header
* Informasi status

Tujuan:
Memberikan kesan aman dan konsisten.

### Merah

Digunakan pada:

* Alert
* Peringatan

Tujuan:
Menarik perhatian pengguna terhadap kondisi penting.

### Putih

Digunakan sebagai warna latar utama.

Tujuan:
Menjaga tampilan tetap bersih dan mudah dibaca.

---

# Typography

Jenis huruf yang digunakan mengikuti standar antarmuka mobile modern dengan tampilan sederhana dan mudah dibaca.

---

# Komponen Utama

## Button

Digunakan untuk:

* Login
* Logout
* Tindakan pada Alert

## Card

Digunakan untuk:

* Menampilkan informasi
* Menampilkan status

## Navigation

Digunakan untuk berpindah antar halaman pada aplikasi.

---

# Konsistensi Desain

Seluruh halaman menggunakan:

* Warna utama yang sama
* Bentuk tombol yang seragam
* Tata letak sederhana
* Struktur informasi yang konsisten

Hal ini bertujuan untuk meningkatkan kemudahan penggunaan aplikasi.
