# User Flow Documentation

## Alur Penggunaan Aplikasi

Splash Screen
↓
Login
↓
Dashboard

Dari Dashboard pengguna dapat membuka:

* Profile
* Alert
* Notifikasi Keluarga

---

## Skenario Penggunaan

### Skenario 1

1. Pengguna membuka aplikasi.
2. Splash Screen ditampilkan.
3. Pengguna melakukan Login.
4. Sistem menampilkan Dashboard.

### Skenario 2

1. Pengguna berada pada Dashboard.
2. Sistem menampilkan Alert.
3. Pengguna melihat informasi kondisi yang diberikan sistem.

### Skenario 3

1. Sistem mengirimkan notifikasi.
2. Informasi ditampilkan pada Screen Notifikasi Keluarga.
3. Keluarga dapat melihat detail kondisi yang diterima.

### Skenario 4

1. Pengguna membuka halaman Profile.
2. Pengguna melihat informasi akun.
3. Pengguna dapat melakukan Logout.
