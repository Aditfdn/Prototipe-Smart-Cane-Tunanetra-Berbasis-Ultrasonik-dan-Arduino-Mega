# UI/UX Design Documentation

## Deskripsi Proyek

S-CANE (Smart Cane for Avoidance and Notifying Electronics) merupakan sistem yang membantu pengguna memperoleh informasi kondisi sekitar melalui notifikasi pada aplikasi mobile.

Antarmuka aplikasi dirancang sederhana agar pengguna dapat mengakses informasi utama dengan cepat dan mudah.

---

# Daftar Halaman

## 1. Splash Screen

Splash Screen merupakan halaman pertama yang ditampilkan saat aplikasi dibuka.

Fungsi:

* Menampilkan identitas aplikasi S-CANE.
* Memberikan proses loading sebelum masuk ke halaman berikutnya.

---

## 2. Login Screen

Halaman Login digunakan untuk masuk ke aplikasi.

Komponen:

* Input Username
* Input Password
* Tombol Login

Fungsi:

* Memverifikasi akun pengguna sebelum mengakses aplikasi.

---

## 3. Dashboard

Dashboard merupakan halaman utama setelah pengguna berhasil login.

Komponen:

* Menu navigasi
* Informasi status
* Ringkasan aktivitas

Fungsi:

* Menampilkan informasi utama sistem.
* Menjadi pusat navigasi menuju halaman lain.

---

## 4. Profile Screen

Halaman Profile digunakan untuk menampilkan informasi pengguna.

Komponen:

* Nama pengguna
* Informasi akun
* Tombol Logout

Fungsi:

* Menampilkan identitas pengguna.
* Keluar dari aplikasi.

---

## 5. Screen Alert

Screen Alert digunakan ketika sistem memberikan peringatan kepada pengguna.

Komponen:

* Status bahaya
* Status berhasil ditangani
* Tombol tindakan

Fungsi:

* Menampilkan kondisi yang membutuhkan perhatian pengguna.

---

## 6. Screen Notifikasi Keluarga

Halaman ini digunakan untuk menampilkan informasi notifikasi kepada keluarga.

Komponen:

* Informasi kondisi pengguna
* Detail notifikasi
* Status kondisi

Fungsi:

* Memberikan informasi kepada pihak keluarga mengenai kondisi yang terdeteksi oleh sistem.

---

# Kesimpulan

Desain antarmuka S-CANE dibuat dengan pendekatan sederhana dan mudah digunakan. Seluruh halaman memiliki fungsi yang jelas sehingga pengguna dapat memahami informasi yang diberikan oleh sistem dengan cepat.
