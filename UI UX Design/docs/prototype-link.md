## Deskripsi

Prototype ini berisi desain antarmuka aplikasi S-CANE yang digunakan sebagai media visualisasi sistem.

Halaman yang tersedia pada prototype:

* Splash Screen
* Login Screen
* Dashboard
* Profile Screen
* Screen Alert
* Screen Notifikasi Keluarga

## Tujuan

Prototype digunakan untuk:

1. Menampilkan rancangan antarmuka aplikasi.
2. Membantu proses evaluasi desain sebelum implementasi.
3. Menunjukkan alur interaksi pengguna pada sistem S-CANE.
4. Menjadi referensi pengembangan antarmuka aplikasi.

## Catatan

Desain pada Figma digunakan sebagai acuan utama dalam proses pengembangan tampilan aplikasi S-CANE.
