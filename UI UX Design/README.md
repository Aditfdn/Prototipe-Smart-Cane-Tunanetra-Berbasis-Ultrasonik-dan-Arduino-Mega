# S-CANE UI/UX Design

## Overview

S-CANE (Smart Cane for Avoidance and Notifying Electronics) merupakan proyek pengembangan antarmuka aplikasi mobile yang digunakan untuk menampilkan informasi dari sistem Smart Cane.

Dokumentasi ini berisi desain antarmuka pengguna (UI) dan alur interaksi pengguna (UX) yang digunakan pada aplikasi S-CANE.

---

## Available Screens

### Splash Screen

Menampilkan identitas aplikasi saat pertama kali dijalankan.

### Login Screen

Digunakan untuk autentikasi pengguna sebelum masuk ke sistem.

### Dashboard

Halaman utama yang menampilkan informasi dan navigasi aplikasi.

### Profile Screen

Menampilkan informasi akun pengguna.

### Alert Screen

Menampilkan peringatan atau kondisi yang membutuhkan perhatian pengguna.

### Family Notification Screen

Menampilkan informasi notifikasi yang diterima keluarga.
