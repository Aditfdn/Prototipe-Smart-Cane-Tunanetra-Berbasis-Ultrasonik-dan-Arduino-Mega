# Smart Cane: Sistem Navigasi Tunanetra Berbasis Arduino Mega

## Deskripsi Proyek

Menggunakan mikrokontroler Arduino Mega (ATMega2560), sensor ultrasonik untuk deteksi dan navigasi jarak, sensor *water level* untuk mendeteksi genangan air atau permukaan basah, serta modul DFPlayer Mini untuk memberikan output berupa panduan suara (*voice commands*) melalui *earphone* atau *speaker*. Alat ini dirancang berbentuk tongkat cerdas untuk meningkatkan mobilitas dan keamanan penyandang tunanetra saat berjalan.
